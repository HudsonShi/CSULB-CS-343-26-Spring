# Requirements Analysis

## Pre-requisite Knowledge

1. pre-sales get requirements from the customer party A. And ask product manager if the requirements are feasible.
2. product manager will analyze the requirements and translate the requirement into PRD (Product Requirement Document).
3. The SDE analyzes the PRD and translate it into technical requirements.
4. CRUD (Create, Read, Update, Delete) operations are defined based on the technical requirements.
5. MVC (Model-View-Controller) architecture is used to structure the application.
6. API -> Restful API is designed to allow interaction with the application back end server
